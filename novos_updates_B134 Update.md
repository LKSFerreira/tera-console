![Imagem com a skill Godsfall sendo exibida](https://cs-live-static-psap.krapaas.com/console/tera/brand-site/admin/B134_10.png)

Can only be used when Ragnarok Points reaches 1000 after activating Godsfall.

Duration: 25 sec
STR +16% / Attack Speed +40 / Attack Range +20% / Skill cooldown under 60 sec reduced by 60%
