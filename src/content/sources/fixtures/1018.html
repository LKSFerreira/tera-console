Patch Note · TERA Console · B133.02

B133.02 Update — July 23

Greetings, this is the TERA Console Operations Team.
Here are the details of the July 23 (Thu.) update.

Dungeon

Ice Throne
The knockback distance of Boss 2's crescent pattern has been reduced. (Fixed an issue where players were occasionally launched outside the map)
Rampaging RK-9 Kennel / RK-9 Kennel (Hard)
The HP of the timed bomb has been significantly reduced.
Rampaging RK-9 Kennel
The reflection effect of Boss 1 has been removed.
Damage reduction during Boss 3's perfect defense has been increased.
The defense reduction benefit based on the number of Brain Fog pattern triggers for all bosses is now visualized.

Class

Reaper
Grim Strike
Chained Glyph duration changed: 3s → 6s
Cable Step
Attack Speed Boost Glyph duration changed: 2.5s → 3.5s
Binding Scythes
Initial stack activation speed has been increased.
Archer
Find Weakness
Effect release trigger rolled back: 1–2 random → 1
Effect correction for arrow generation on use has been added.

Shop

Condensed Dungeon Core Exchange Condition Changes
Condensed Dungeon Core exchange rates have been reduced and purchase limits have been increased.
Dungeon Core (Kaia) Shop
Price 250 → 200 / Purchase limit 2 → 4
Dungeon Core (Annihilation) Shop
Price 25 → 15 / Purchase limit 4 → 10

Bug Fixes

Fixed an issue where a different NPC was assigned to a Guild Mission.
Fixed an issue where some patterns of RK-9 Boss 2 were occasionally cancelled.
Fixed an issue where the Hexapleon-related electric bomb pattern of RK-9 Boss 2 was cancelled when a player briefly moved out of range at a specific timing.
Fixed an issue in RK-9 Kennel (Hard) where, after completing Boss 3's shield pattern and resetting the NPC, Hard Mode was still applied even when object interaction was ignored, and the leaderboard record time was accumulated with the pre-reset time.
Fixed an issue where Ninja's Burning Heart was not affected by Attack Speed.
Fixed an issue where Ninja's Burning Heart damage increase effect was not applied based on usage count.

Thank you. — TERA Console Operations Team
